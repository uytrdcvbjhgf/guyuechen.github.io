# Project Instructions

This repository is a Hugo personal blog already deployed at https://guyuechen.icu.

Do not modify layout, theme, asset, deployment, or site-structure files unless the user explicitly asks for it.

For writing and editing blog articles, work primarily under `content/posts/` and read the project writing memory in:

- `.codex/blog-profile.md`
- `.codex/writing-style.md`
- `.codex/post-frontmatter.md`
- `.codex/taxonomy.md`
- `.codex/workflows.md`

When creating or revising posts, preserve the existing TOML front matter style and the current Hugo/PaperMod conventions.

For cloud environment setup or continuing the blog collaboration in a new cloud chat, also read `.codex/cloud-handoff.md`.

For receiving Daywise handoffs, use the project skill [handoff-in](.agents/skills/handoff-in/SKILL.md).
It reuses the writing and publishing rules above; handoff materials do not authorize publication.
New skills may require a new task/session for discovery; the skill file can also be read directly.

For discovering open-source skills, read [find-skills](.agents/skills/find-skills/SKILL.md).
See [project skill usage and maintenance](docs/skills.md) for persistence, updates, and network requirements.

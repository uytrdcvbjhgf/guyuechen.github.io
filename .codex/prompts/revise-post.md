# Prompt: Revise Post

Use this when polishing an existing article.

```text
Please revise this existing blog post.

Before editing, read:
- AGENTS.md
- .codex/blog-profile.md
- .codex/writing-style.md
- .codex/post-frontmatter.md
- .codex/workflows.md

Keep the author's meaning and voice.
Improve structure, clarity, transitions, and Markdown readability.
Do not change layout/theme files.
Only adjust front matter if it is missing, invalid, or I explicitly ask.

Target file:
content/posts/<path>.md

Revision goal:
<describe the goal>
```

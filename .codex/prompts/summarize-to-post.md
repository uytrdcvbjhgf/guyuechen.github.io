# Prompt: Summarize To Post

Use this when turning loose notes into a blog draft.

```text
Please turn the following notes into a Hugo blog draft.

Before writing, read:
- AGENTS.md
- .codex/blog-profile.md
- .codex/writing-style.md
- .codex/post-frontmatter.md
- .codex/taxonomy.md
- .codex/workflows.md

Create the article under content/posts/.
Use TOML front matter and set draft = true.
If any facts are uncertain, keep them visibly marked instead of inventing details.

Topic:
<topic>

Raw notes:
<paste notes here>
```

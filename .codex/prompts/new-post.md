# Prompt: New Post

Use this when creating a new blog article.

```text
Please create a new Hugo Markdown post under content/posts/.

Before writing, read:
- AGENTS.md
- .codex/blog-profile.md
- .codex/writing-style.md
- .codex/post-frontmatter.md
- .codex/taxonomy.md
- .codex/workflows.md

Use TOML front matter with draft = true by default.
Write in Chinese unless I ask otherwise.
Preserve the existing blog layout and only edit content-related files.

Topic:
<describe the topic>

Target category/tag ideas:
<optional>

Notes or source material:
<paste notes here>
```

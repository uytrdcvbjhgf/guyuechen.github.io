# Blog Profile

Site: https://guyuechen.icu

This is a personal technical blog built with Hugo and PaperMod. The layout is considered stable; daily collaboration should focus on article content under `content/posts/`.

The blog is used for:

- technical notes and engineering summaries
- backend, Java, frontend, operations, SQL, automation, finance, and system design articles
- work and study reflections when they are useful as reusable notes
- publishing polished Markdown articles with Hugo-compatible front matter

Default writing language: Chinese.

Audience assumptions:

- primary reader is the author in the future
- secondary readers are engineers or technically curious peers
- articles should be clear enough to revisit months later without needing the original chat context

Collaboration preference:

- favor practical article drafts over abstract outlines
- preserve the author's voice and existing structure when revising
- make focused edits unless the user asks for a larger rewrite
- keep generated content publishable as Markdown

# Codex Blog Memory

This directory stores portable, versioned collaboration rules for writing this personal blog.

It is intentionally committed to Git so the same writing workflow can be reused across devices, including macOS and Windows.

Keep this directory limited to public-safe, long-lived project knowledge:

- blog positioning and audience
- article style preferences
- front matter rules
- category and tag conventions
- reusable prompts and workflows

Do not store private secrets, account credentials, API keys, sensitive personal notes, or full chat transcripts here.

Recommended entry point for future Codex sessions: read `AGENTS.md` first, then the relevant files in this directory.

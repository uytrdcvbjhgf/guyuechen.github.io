# 配图字体

用户于 2026-11-02 选择小样 A：**HuiFontP29 / ふい字Ｐ v2.9**，作为今后博客配图文字的默认字体。
适用于情境漫画、流程图、信息图的标题、对白、标注、数字及拉丁文字；不改变网站正文的字体。
漫画画法继续遵循 `.baoyu-skills/baoyu-article-illustrator/visual-guide.md`。

唯一机器配置在 [illustration-typography.json](../.baoyu-skills/illustration-typography.json)，
记录用户所给字体的 SHA-256、名称和本地定位方式。不要只凭文件名认定是同一字体。

## 缺字处理

先确定意思，再核对最终每个字符是否在该字体 cmap 中有实际非空字形轮廓：
该字体的「你」「份」有 cmap 项却没有轮廓，不能只检查字符表或浏览器字体加载状态。

1. 优先把缺失的简体字转换成字体支持的繁体字，例如「核实」改为「核實」。
2. 繁体仍缺字时，改用不改变原意的同义字词，例如「這三張就夠」改为「這三張就好」，
   「啟動任務」改为「開始任務」，「先給你看看」改为「先看看草稿」，
   「一份完整報告」改为「一篇完整報告」。不能为了凑字而改变事实、否定、数量、单位或流程。
3. 对换词后的完整句子重新检查，包括标点、数字、英文。无法保持意思时，移到正文解释或请用户决定。

不允许静默回退到其他字体、缺字方框、由模型仿写目标字体，也不人为扭曲、旋转每个字来制造手写感。
简转繁只作用于图片文案，不批量转换文章正文。

## 真实字体排字

默认先用原生图像工具制作无字底图，保留空对白框、图形和连接，再把审核后的文字作为独立层，
以真实 TTF 排版并导出最终 PNG。旧图换字也先用图像工具取得无字底图，不能用色块盖住旧字再补字。
这是用户明确选择真实字体后的项目排版流程，优先于上游技能禁止文字叠排的一般约定；
图像创作仍使用原生工具，不用 HTML 或代码重画角色与图形。不能声称图像模型加载了 TTF。

辅助工具 [illustration-typography.py](../scripts/illustration-typography.py) 使用 fontTools 检查字体哈希与字形，
使用 Playwright/Chromium 对无字底图和真实文字层进行合成。依赖为 Python 3、fonttools、Pillow（只读尺寸）及
playwright；浏览器路径默认 `/usr/bin/chromium`，可用 `--chromium` 指定。工具不会安装依赖或发布资源。

```sh
python scripts/illustration-typography.py check /tmp/image-copy.txt
python scripts/illustration-typography.py render /tmp/typesetting.json /tmp/final-images
```

排版 JSON 为 `{"schema_version":1,"images":[...]}`；每项含 `id`、`background`（相对清单路径）、
`labels`。每个 label 含 `text`、`x`、`y`、`width`、`height`、`font_size`（像素），可选 `align`（center/left）。
底图需预先完成目视检查；工具拒绝缺字、错误字体、超出画布的文字框及装不下的文字，不自动换词。
导出报告记录真实字体、底图与成品哈希；仍需人工检查字形、气泡留白、阅读尺寸、含义、隐私及图形关系。

## 字体文件与跨任务

本机已保存用户上传的字体到 `/workspace/shared/fonts/HuiFontP29.ttf`。
可通过 `MYNOTE_ILLUSTRATION_FONT` 指向另一份经过相同哈希验证的文件。
字体偏好、哈希、检查工具随仓库持久化；字体文件本身不等于 Git 仓库内容，不能假定全新云环境已经拥有它。
文件不在时先定位用户提供的同版文件；拿不到时明确说明，不能悄悄换字体。
用户上传的 TTF 没有附完整再分发条款，本次不将字体二进制或包含字体数据的 HTML 提交到公开仓库；
使用成品图片不代表已获得字体文件再分发许可，也不把字体的可嵌入标记当作完整授权。

## 资源与发布

最终图片、无字底图、文案及必要提示词统一由 Gallery 管理，清单记录真实文件哈希、尺寸、字体哈希和换词。
不提交本机绝对路径或内嵌字体的调试 HTML。修改使用新资源路径，博客引用 Gallery 的固定完整提交。
因此更换图片通常需要更新文章引用并触发博客部署；不能只推 Gallery 就宣称当前页面已经换图。
发布授权、文章构建、公开页面和实际图片加载验收，继续使用既有流程。
